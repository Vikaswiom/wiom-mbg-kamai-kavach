Who gets it

CSPs with at least one netbox scheduled to start charging on 1 September — nobody else. A CSP already being charged, or whose cadence date is 16 September, must not receive this.

  • The list to send to is here: CSP communication list (Google Sheet) — this is the audience for all three sends.
  • The device-level view behind it — which netboxes each CSP has starting on 1 September — is on WiomHub (internal portal).
  • Pull it fresh on each send day. CSPs drop out daily as they install or return netboxes — a stale list annoys people who have already acted.
Reference

Standard notification card — bold title, grey sub-line.

  • No image, no action buttons.
  • No rupee amount and no netbox count. The date does the work; the numbers live in the app, where the CSP can see the working.
  • Both ways out — install at a customer, or return — are already on the screen the tap leads to, so the push does not need to carry them.
